# Data

This project uses two publicly available metabolomics datasets. Raw data is
not checked into this repository — download from the original sources:

- **MTBLS8644** — [MetaboLights entry](https://www.ebi.ac.uk/metabolights/MTBLS8644)
- **iPOP** — described in Zhou et al., *Nature Medicine* 2019
  ([paper](https://www.nature.com/articles/s41591-019-0509-0)); data hosted
  on a public GCS bucket.

Place downloaded files here locally before running the scripts in `scripts/`.
